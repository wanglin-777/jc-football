# ⚽ 竞彩足球·两串一预测模型

基于**中国体彩·竞彩足球官方实时数据**的胜平负概率分析 + **两串一**智能推荐项目。

- 自动抓取**当天可购买的竞彩场次 + 官方胜平负/让球赔率 + 联赛排名**（实时真实数据）
- 结合每队**最近约 10 场**真实赛果（近期加权）做攻防强度分析
- 输出每场 **胜/平/负 概率**，并按你的玩法给出 **5 组「两串一」**推荐
- 规则内置：**只串两关 · 串后赔率 ≥ 2.0 · 按两场联合胜率从高到低**

> ⚠️ **重要声明**：本工具是对历史数据与官方赔率的统计分析，仅供研究参考，**不构成投注建议**。
> 足球比赛充满偶然性，请理性购彩、量力而行，未成年人不得购彩。

## 🧠 模型怎么算的？

对每场比赛，模型融合两路信息：

1. **泊松比分模型**：用每队最近 ~10 场（越近权重越高）的进/失球，
   按**主客场**分开计算攻防强度 → 推算主/客预期进球 λ → 枚举比分得 P(胜/平/负)
2. **官方赔率隐含概率**：把胜平负赔率去掉庄家水分，得到"市场共识"概率

> 欧洲主流联赛 9 月刚开赛几轮、近期样本小，官方赔率是更强的先验，
> 因此**历史模型只做温和修正**，避免小样本过度自信。
> 当某场缺少历史数据时，自动降级为「仅赔率预测」并在界面明示。

**两串一**：先给每场挑出模型胜率最高的选项（胜率门槛以上）组成"稳胆池"，
再枚举任意两场的组合，筛出 **串后赔率 ≥ 2.0** 的组合，按 **p₁×p₂** 联合胜率
从高到低取前 5 组（兼顾每场比赛最多出现 2 次的多样性）。

## 📝 手动补充情报（伤病 / 转会 / 教练 / 战意 / 热度）

这些信息**没有免费稳定的自动数据源**，工具提供手动录入入口 `data/extra_intel.json`：
```json
{
  "matches": [
    {
      "num": "周六004", "home": "纽卡斯尔", "away": "伯恩茅斯",
      "adj": 1,
      "reason": "主队核心前锋复出；客队主力中卫停赛；主队争欧战席位战意强"
    }
  ]
}
```
- `adj`：`-3 ~ +3` 整数，**正数利好主队**、负数利好客队，会小幅修正概率
- `reason`：中文说明，会展示在网页
- 保存后**刷新网页**即生效

> 💡 可以配合新闻/伤停网站（自行判断来源可靠性）来填。系统会把缺失这些信息的场次
> 用「联赛排名 / 让球盘 / 赛程密度」等代理信号兜底并如实标注。

## ❓ 常见问题

- **为什么有些场次显示「仅赔率预测」？** 该场所在联赛没有接入历史数据源，或两队队名
  尚未在 `team_map.py` 映射。属正常降级，不影响整体功能。
- **为什么推荐里没有某场？** 该场胜平负未开（如强弱悬殊场只开让球），或最高胜率选项
  低于稳胆门槛（当前默认 45%）。
- **没网能用吗？** 数据已抓过缓存到 `data/` 后可以离线查看；联网后点「强制联网更新赔率」即可刷新。
- **怎么做到"随时打开"？** 双击一次 `安装开机自启.bat`，之后电脑每次开机都会自动在后台运行网页服务；
  平时只需浏览器打开 http://localhost:8501（或双击桌面快捷方式）即可，无需每次手动启动。
- **网页打不开/连不上？** 多半是后台服务没运行。双击 `启动网页版.bat` 即可；若仍不行，双击 `停止服务.bat` 后再启动一次。
- **想在外面(非本机 WiFi)也能开？** 需要电脑开机 + 公网访问手段（如把服务部署到 Streamlit Community Cloud 或加免费隧道）。
  本机范围内(含家里 WiFi/手机)上述"开机自启"方式即可。
