# ⚽ 竞彩足球 · 两串一预测

基于中国体彩·竞彩足球数据的 **胜平负概率分析 + 两串一推荐**。

- 🌐 **公开网页(云端)**：托管在 GitHub Pages，**任何时间、任何网络**都能打开
- 🔁 **每 4 小时自动更新**：由你电脑上的定时任务抓取竞彩最新数据并推送，网页随之刷新
- 📊 每场 **胜/平/负 概率** + **5 组「两串一」**（只串两关 · 串后赔率≥2 · 按联合胜率排序）

> ⚠️ 本工具是对历史数据与赔率的统计分析，仅供研究参考，**不构成投注建议**；
> 足球充满偶然性，请理性购彩、量力而行，未成年人不得购彩。

## 🔁 为什么需要电脑"定时更新"？

竞彩数据来自**中国体彩官网**，它**封锁境外 IP**（海外返回 HTTP 567），GitHub 的云端机器读不到。
所以采用分工：
- **网页由 GitHub 云端承载** → 随时打开（不受影响）
- **数据由你的电脑每 4 小时抓取并推送** → 电脑开机时自动完成（每次只需几秒）

> 电脑关机时网页仍能打开，只是数据停在最近一次抓取。

## � 数据存哪（约定）

**GitHub = 唯一权威数据源；本机只保留“重要”的：程序代码 + DeepSeek Key + 定时任务。**

- 所有比赛数据（当天快照 / 每赛季赛果 / 每日预测账本 / CSV / 网页）都存/推送到 GitHub：
  - `data/today_matches.*` 当天快照 · `data/history/` 每日账本 · `data/history_csv/` 可读表
  - `data/cache/` 整季赛果备份 · `docs/` 网页
- 本机 `data/` 只是 Git 仓库的**本地镜像**，并非重要数据：几 MB、删了也不怕，
  随时用 `从GitHub同步数据到本机.bat` 从 GitHub 拉回（`git reset --hard origin/main`）。
- 真正留本机不传的只有：`data/deepseek_key.txt`（机密）等本地私有文件。

> 结论：本机坏/重装/换机器都不影响——代码与历史都在 GitHub；这台电脑随时可“退居只浏览”。

## 🧠 模型怎么算
- 每队最近约 10 场(近期加权)攻防强度 → **泊松比分** → P(胜/平/负)
- 与**赔率隐含概率**(去水分)融合；缺历史时自动降级「仅赔率预测」并明示
- **两串一**：每场取胜率最高选项入池 → 任意两场组合、串后赔率≥2 → 按 p₁×p₂ 取前 5 组

## 离线评估与回归测试

```bash
python evaluate.py
python -m unittest discover -s tests -v
```

评估只读取 `data/history/` 预测存档和 `data/verified_cache/` 已核验赛果，
不联网、不调用 DeepSeek、不修改数据。输出样本量、首选命中率、三分类 Brier
分数（各类别平方误差之和，范围 0～2）和对数损失；后两项越低越好。
这些指标衡量现有存档，不代表修改后的模型已获得相同表现，也不是严格的时间外回测。
现有存档缺少完整的预测时点与当时特征，不能据此证明新版本提高了准确率。

概率计算保留真实的零进球数据、拒绝非法赔率，并防止平局修正产生负概率。
自动校准使用每场完整的胜平负概率与实际赛果；相同数据重复刷新不再累积调整，
修正赛果或预测概率后会重新计算。新校准在下一次正常复盘刷新时生效。

## 新版比赛工作台

运行 `python build_site.py --offline` 使用本地缓存生成 `docs/index.html`，直接打开即可预览。
离线模式不联网、不调用 DeepSeek、不更新历史账本或校准参数，只生成网页与页面快照。
正常联网更新仍使用 `python build_site.py`，原有 GitHub Pages 发布目录不变。

- 保留原站名称、串关方案首屏和原有栏目；全部概率表增加筛选、排序和三向概率条。
- 展开表格中的预测依据可查看市场基线、历史模型占比和情报摘要；数据不足时明确标注。
- 保留总进球、爆冷雷达、预测验证和自我复盘，改善字号与手机横向滚动。
- 复盘展示 Brier、对数损失；只在双方概率均有存档的同一批比赛上比较市场基线。
- 新赛前记录保存北京时间的预测/开赛时间、模型版本、特征与市场概率；开赛或停售后保留旧预测。
- 联赛基线排除比赛当日及其后的赛果；修复客场交锋平局被误记为胜的问题。
- 生成失败返回非零状态并保留旧网页，自动更新流程停止本次推送。

按日期评估：`python evaluate.py --since 2026-09-05 --until 2026-09-07`。
旧记录无法补出真实的赛前特征或市场概率；新记录需要积累赛果后才能判断改进效果。

## 历史攻防模型改进与回测

`python backtest.py` 只读取联赛缓存，按时间推进构建特征，并生成 `data/backtest_report.json`。
验证期在 3、6、12 三个收缩参数中选择，测试期不选参数。本轮选中 12，
保留测试期 353 场的历史子模型首选命中率 47.59% → 49.58%，Brier 0.6302 → 0.6186。
命中率差的按日期重采样 95% 区间仍包含零，尚不能认定命中率存在稳定提升。

这些结果只适用于有历史数据的攻防子模型，不含历史赔率、人工情报或复盘校准，
不能宣称完整竞彩预测已提升同等幅度；当前缓存赛果也未在本轮另行核实。
新赛前账本同时保存当前预测、原攻防算法的融合预测与市场基线，以后用同一批实际赛果比较。
缺历史时继续使用赔率分支；独立总进球玩法保留原算法。
若需切回原攻防算法，在 `config.py` 设置 `HISTORY_MODEL_VARIANT = "legacy"`。
